# poker-hand-evaluator
takes in two poker cards, and plots a graph of win probability on number of players 

takes in two poker cards, converts them into a number form. We then run a monte carlos simulation which simulates a river from the remaining deck (minus the two selected cards) and then possible hands for the number of selected opponents
we cycle through the number of opponents from 1 to the inputted number, and find the win rate for each, plotting a graph of this on the number of opponents.
